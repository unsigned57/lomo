# 工作区切换与索引性能

本文记录当前工作区索引、目录观察、写后刷新与同步规划的性能机制、可重复实验及适用边界；
模块权限由 [Architecture](../../ARCHITECTURE.md) 定义，验证规则由 [Quality](../../quality/README.md) 定义。

## 核心机制

- **有界目录观察与分页**：SAF 在提供器连接有效时一次性读取元数据游标后关闭连接，通过绑定树、目录、
  观察轮次与位置的不透明游标分页；Rust 文件适配器仅枚举排序一次名称，按页获取实时元数据。
  未完成观察限制为最多 16 个、合计约 64 MiB（SAF 单个元数据观察约 16 MiB），越界、失效或重用均显式报错，
  不跨调用持有提供器连接或目录描述符。新增成员由下一轮全新枚举发现。
- **缺席记录与批量历史加载**：增量重建使用 `RecordPresence`（完整枚举加本轮已验证的自身写入）
  识别缺失 tombstone 与 state head，避免对不存在路径重复发起根目录重验；已有历史按最多 8 个头再最多 8 个对象
  分阶段校验加载；增量变更集合统一进入最多 8 路并发扫描器后再统一发布投影。
- **写后观察计划与 `Inspect` 动作**：少量写入按最多 8 个精确路径查询，大批量导入切回单次批量列举；
  新增 `Inspect` 平台动作仅取元数据与变更 token（内容摘要保持 `Unknown`），内容仲裁与写入校验继续使用原 `Stat`/CAS 路径。
- **句柄优先替换**：编辑写路径优先使用缓存的正向句柄实时校验名称与内容摘要后再覆写，失效或不符时回退按名称列举。
- **同步查找与目录批处理**：`lomo-sync` 在单次操作生命周期内从事实建立借用路径索引与本地路径集合，不改变持久化格式；
  WebDAV 对同一发布批次已成功建立的父目录仅请求一次 `MKCOL`。

Architecture Impact：目录观察由 Android `data` 与 `lomo-platform-fs` 各自拥有；历史分阶段加载与写后观察计划由
`lomo-application` 拥有；`lomo-core` 定义 `Inspect` 协议，`lomo-native` 仅作 FFI 转换；同步规划由 `lomo-sync` 拥有。

## 可重复实验与代表性对比

```bash
cargo run -p lomo-application --example workspace_path_probe --release --locked -- 1200 8 3
cargo run -p lomo-sync --example sync_scaling_probe --release --locked
just perf device workspace --corpus device --backend saf --trace
just build android benchmark workspaceReopen
```

- **主机 9600 笔记文件系统分页对照**（`1200` 文档 × `8` 笔记 × `2` 根 × `3` 次，`workspace_path_probe`）：
  切回已有索引 p50 `277.87 -> 138.64 ms`（`-50.1%`），无改动扫描 `258.46 -> 152.98 ms`（`-40.8%`），
  新增文档扫描 `622.13 -> 425.79 ms`（`-31.6%`），首次索引 `1444.12 -> 1298.99 ms`（`-10.0%`）；
  已有历史完整重建为 `1164.58 -> 1198.17 ms`（读取与校验全部历史仍是实际成本）。
- **Android SAF 大库（redroid x86_64、debug APK、约 9850–9870 笔记）**：
  - 写后元数据观察（`saf-large`）：外部修改后扫描 p50 `7905.38 -> 4371.57 ms`（`-44.7%`）；
    切库（`3569 -> 3593 ms`）与无改动扫描（`3511 -> 3517 ms`）不变，因为全量元数据枚举仍保留外部变更检测。
  - 句柄替换写路径（5 次不同内容提交）：编辑提交 p50 `3715.95 -> 573.23 ms`（`-84.6%`），
    100 次替换边界测试将目录枚举从 `101` 次降至 `1` 次。
  - 这些数字为模拟器/debug 相对证据，不能替代真机 release 测试。
- **同步规划 CPU（`sync_scaling_probe`，每规模 5 次）**：
  `1000` 路径 `4.59 -> 0.78 ms`；`5000` 路径 `102.37 -> 4.64 ms`；`10000` 路径 `401.74 -> 9.66 ms`；
  `20000` 路径 `1200.14 -> 22.12 ms`（纯规划 CPU，不含网络与磁盘 IO）。
