## Lomo v2.0.3

Reduced repeated work when opening the timeline, search results, and gallery. Improved attachment scanning and trash cleanup, and fixed stale sync status after workspace switches.

Lomo v2.0.3 减少了加载时间线、搜索结果和相册时的重复工作，改进了附件扫描与回收站清理，并修复了切换工作区后显示旧同步状态的问题。

### ✨ New Features and Improvements / 新功能与改进

- **Lighter note previews and gallery pages / 减轻笔记预览和相册的加载开销**
  Reused note previews across image updates and reduced the data needed to browse the gallery. The gallery loads the full note when you open its details.
  图片更新时复用笔记预览，并减少浏览相册时读取的数据。打开笔记详情时再加载完整正文。

- **Batched attachment scanning and trash cleanup / 批量扫描附件与清空回收站**
  Grouped attachment classification and processed large trash cleanups in batches. If cleanup is interrupted, completed deletions are retained and the remaining notes stay in the trash.
  批量识别附件类型，并分批清理大型回收站。如果清理中断，已完成的删除会保留，其余笔记仍在回收站中。

### 🐞 Bug Fixes / 缺陷修复

- **Sync status after switching workspaces / 修复切换工作区后的同步状态**
  Cleared outgoing sync status and prevented old conflict results from appearing after a workspace switch.
  切换工作区时清除上一个工作区的同步状态，避免旧冲突结果出现在新工作区中。

- **Opening Android document folders / 修复 Android 文档目录打开问题**
  Handled temporary provider loading during startup and revalidated the target before writing to a document folder.
  处理启动时文档提供程序的临时加载状态，并在写入文档目录前重新验证目标。
