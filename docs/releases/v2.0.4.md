## Lomo v2.0.4

Added "Save to Lomo" to Android's system text selection toolbar for instant note capture, introduced support for workspaces with mixed filename and timestamp formats alongside file-native date and time display, unified share card rendering with the in-app Markdown experience, simplified image and voice folder setup, reduced repeated work across previews, gallery browsing, attachment scanning, and trash cleanup, and resolved timestamp display after upgrades, workspace-switching sync leaks, and Android document-folder startup issues.

Lomo v2.0.4 在 Android 系统文本选中工具栏中新增「保存到 Lomo」快捷记入入口，支持在同一工作区中兼容多种文件名与时间戳格式并按文件原生日期与时间展示，使用与正文一致的 Markdown 渲染导出分享卡片，简化了图片与语音目录配置，降低了笔记预览、相册浏览、附件扫描与回收站清理的开销，并修复了升级后原有笔记缺失时间显示、切换工作区后的同步状态串扰以及 Android 文档目录启动问题。

### ✨ New Features and Improvements / 新功能与改进

- **Text selection toolbar quick capture ("Save to Lomo") / 系统文本选中工具栏快捷记入（「保存到 Lomo」）**
  Added a dedicated "Save to Lomo" action to Android's system text selection toolbar so selected text from other apps opens directly in Lomo's note input sheet; returns to the home feed when triggered from secondary screens, preserves unsaved drafts or active editing sessions, and waits behind App Lock or workspace setup when needed.
  在 Android 系统文本选中工具栏中加入明确的「保存到 Lomo」选项，在其他应用中选中文本后可直接打开 Lomo 笔记输入框并填入内容；从二级页面触发时会自动回到主页，完整保留未保存草稿或当前正在编辑的笔记，并在需要时等待应用锁解锁或工作区就绪后再执行。

- **Mixed date formats and file-native date/time display / 兼容混合日期格式并展示文件原生日期与时间**
  Decoupled workspace scanning from note creation formats so workspaces mixing multiple supported filename and timestamp formats load seamlessly while new or imported notes use the selected storage formats; removed redundant global display date/time format settings and now display each note's native date and time exactly as stored in its file (such as `yyyy_MM_dd HH:mm:ss` or `MM-dd-yyyy HH:mm`) on cards and share images.
  解耦了工作区扫描格式与新建笔记格式：加载工作区时自动兼容混合存在的多种受支持文件日期与时间戳格式，仅在新建或导入笔记时使用当前选定的存储格式；同时精简了冗余的全局展示格式设置，在笔记卡片与分享图片中直接按文件原生格式展示每条笔记的日期与时间（例如 `yyyy_MM_dd HH:mm:ss` 或 `MM-dd-yyyy HH:mm`）。

- **Unified Markdown share card rendering / 分享卡片改用统一 Markdown 渲染**
  Replaced the separate share card renderer with the app's own theme and Markdown renderer so exported share images preserve typography, custom fonts, code blocks, tables, and inline formatting consistently.
  改用应用自身的主题与 Markdown 排版引擎生成分享长图，替代原有的独立绘制方案，使导出的图片完整保持应用字体、排版间距、代码块、表格及行内样式效果。

- **Explicit image and voice directory selection / 明确图片与语音附件目录配置**
  Removed automatic folder-creation prompts and implicit scanning of unconfigured `images/` and `voice/` folders; when an attachment directory is missing, Lomo now navigates directly to Settings so you can choose the exact folder to use.
  移除了缺失附件目录时的自动创建提示以及对未配置 `images/`、`voice/` 文件夹的隐式扫描；当尚未指定图片或语音存储目录时，Lomo 会直接引导前往设置页面，由你明确选择目标文件夹。

- **Lighter note previews, gallery browsing, and batched trash cleanup / 减轻笔记预览、相册加载与回收站清理开销**
  Reused rendered previews across image updates, grouped attachment classification into batches, reduced the data loaded when browsing the gallery (loading full note content only when opening details), and processed large trash cleanups in batches so completed deletions are retained if cleanup is interrupted.
  在图片映射更新时复用已渲染的笔记预览，按批次整理与识别附件类型，减少浏览相册时读取的正文数据（仅在打开详情时加载完整笔记），并对大型回收站进行分批清理，即使清理途中中断，已完成的删除结果也会保留。

### 🐞 Bug Fixes / 缺陷修复

- **File-native time display after upgrading existing workspaces / 修复已有工作区升级后笔记时间缺失的问题**
  Fixed an upgrade issue where existing notes displayed only the filename date without the note's time; workspaces upgraded from earlier versions now automatically rescan and restore each note's full file-native date and time, and uppercase `.MD` filenames are stripped consistently when forming displayed dates.
  修复了已有工作区升级后旧笔记卡片只显示文件名日期、未显示具体时间的问题；从旧版本升级后会自动重新扫描并恢复每条笔记完整的文件原生日期与时间，同时统一处理大写 `.MD` 后缀的文件名显示。

- **Sync status and conflict isolation across workspace switches / 修复切换工作区后的同步状态与冲突串扰**
  Cleared outgoing sync state when switching workspaces, prevented stale statuses or conflict results from a previous workspace from appearing in the new workspace, and properly propagated cancellation across sync and list paging.
  在切换工作区时立即清除上一个工作区的同步状态，防止旧的同步结果或冲突提示在新工作区中显现，并修复了同步与分页加载时的任务取消传播。

- **Android document folder startup and write validation / 修复 Android 文档目录启动加载与写入校验**
  Handled temporary document-provider loading states on cold start with bounded retries, revalidated the target folder before writing, and fixed a startup storage preferences binding issue.
  妥善处理冷启动时 Android 文档提供程序的临时加载状态并加入有限次重试，在写入文档目录前重新校验目标权限与路径有效性，并修复了启动时存储偏好设置绑定异常的问题。

- **Preview isolation, gallery image matching, and trash error reporting / 修复预览缓存串用、相册图片映射与回收站错误提示**
  Scoped cached previews to the exact note text and active workspace, tightened gallery image mapping validation, and preserved clearer failure and cancellation outcomes when emptying the trash.
  将预览缓存严格绑定至精确的笔记正文与当前工作区，收紧相册图片投影与路径校验逻辑，并在清空回收站失败或取消时向调用方保留准确的错误信息与结果回执。
