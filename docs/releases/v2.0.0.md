## Lomo v2.0.0

Rebuilt Lomo's core in Rust and delivered a major upgrade to the Android experience. Added customizable floating-button gestures, fuzzy and pinyin search, OLED pure-black mode with adjustable contrast, variable-font customization, expanded home-screen widgets, and reworked sync and LAN sharing—alongside extensive interface refinements and faster performance from startup to everyday browsing.

Lomo v2.0.0 基于 Rust 重写核心引擎，并为 Android 端带来全方位升级：新增可自定义的手势快捷球、模糊与拼音搜索、OLED 纯黑深色背景与对比度调节、可变字体精细控制，以及更多桌面小组件，同时重构了同步与局域网分享体验，并全面打磨界面质感与从启动到日常浏览的流畅度。

### ✨ New Features and Improvements / 新功能与改进

- **Rebuilt core engine in Rust / 基于 Rust 重写核心引擎**
  Rebuilt Markdown parsing, local indexing, search, synchronization, LAN sharing, and media handling in Rust for faster, more reliable local operations while preserving your local-first Markdown workflow.
  采用 Rust 重写 Markdown 解析、本地索引、搜索、同步、局域网传输与媒体管理等核心能力，在提升数据处理可靠性与响应速度的同时，延续本地优先的 Markdown 工作流。

- **Gesture ball controls / 手势快捷球**
  Upgraded the floating create button into a customizable gesture ball supporting long-press and four-direction swipe gestures for recording, long-form writing, search, filters, daily review, gallery, and more. Sliding back to center cancels a gesture, Settings includes a live gesture preview, and tapping continues to create a new note.
  将悬浮新建按钮升级为可自定义的手势快捷球，支持长按与上下左右滑动手势，可自由绑定开始录音、长文模式、搜索、筛选、每日回顾、图库等快捷操作。滑回中心即可取消触发，设置页内支持试触预览，轻点则继续用于快速新建笔记。

- **Refreshed Material 3 interface / 焕新的 Material 3 界面与交互**
  Refreshed the home feed, editor, search, gallery, daily review, and settings with unified rounded icons, smoother predictive-back gestures and screen transitions, aligned haptic feedback, radial share sub-menus, and new sort and filter options for daily review.
  基于 Material 3 全面焕新首页、编辑器、搜索、图库、每日回顾与设置界面：统一圆润风格的图标体系，优化预测返回手势与页面转场动效，细化触觉反馈，为操作菜单加入径向展开的分享子菜单，并为每日回顾新增排序与筛选条件。

- **Fuzzy and pinyin search / 模糊与拼音搜索**
  Introduced a fuzzy search mode alongside exact full-text search, supporting full pinyin, pinyin initials, and non-contiguous character matching so you can locate notes even from partial or approximate queries.
  在精准全文搜索之外新增模糊搜索模式，支持全拼、拼音首字母及非连续字符匹配；即使只记得零散字词或拼音缩写，也能快速找到相关笔记。

- **OLED pure black and theme contrast / OLED 纯黑与主题对比度**
  Added a pure-black dark-mode option for OLED screens—working in both dark mode and system-following dark appearance—along with Standard, Medium, and High contrast levels and live color-scheme previews.
  为深色模式新增适合 OLED 屏幕的纯黑背景选项，在手动深色与跟随系统模式下均可生效；同时新增标准、中等、高三档主题对比度调节与实时配色预览。

- **Variable-font controls / 可变字体与自定义字体增强**
  Enhanced custom-font support with font file imports up to 200 MB and interactive controls for supported variable-font axes—such as weight, width, optical size, and slant—applied consistently across reading, editing, and shared cards.
  增强自定义字体支持，支持导入最大 200 MB 的字体文件，并开放可变字体轴的实时调节（如字重、字宽、视觉尺寸与倾斜度等），让阅读、编辑与分享卡片呈现一致的排版效果。

- **Expanded home-screen widgets / 丰富的桌面小组件**
  Expanded the widget suite with Quick Notes, Tasks, Heatmap & Streak, and Daily Memory, letting you capture notes, check off Markdown todos, track writing streaks, and revisit past memos from your home screen—with widget contents hidden automatically when App Lock is enabled.
  扩展为四款桌面小组件——「速记与动态」「待办清单」「热力图与统计」与「每日回顾」，无需打开应用即可在桌面快速记录、直接勾选 Markdown 待办、查看写作连续天数与热力图，以及重温往日笔记；开启应用锁后，小组件内容会自动隐藏以保护隐私。

- **Synchronization and LAN sharing / 同步与局域网分享升级**
  Reworked Git, WebDAV, and S3 synchronization for steadier runs, added a dedicated Sync Center with expanded sync-status and conflict-resolution views, and upgraded local-network sharing with mutual device verification and batch transfers.
  重构 Git、WebDAV 与 S3 同步机制以提升稳定性，新增「同步中心」及更直观的同步状态与冲突处理界面，并将局域网分享升级为支持双向设备核验与批量传输。

- **Startup and large-workspace performance / 启动与大工作区性能提速**
  Accelerated app startup, workspace loading and switching, search responsiveness, and media loading while reducing redundant refresh work, keeping scrolling and daily browsing smooth even in large note libraries.
  全面优化应用冷启动、工作区加载与切换、搜索响应及图库媒体加载，并减少刷新时的重复开销；即使面对体量庞大的本地笔记库，列表滑动与日常浏览依然轻快流畅。

### 📦 Upgrade Notes / 升级说明

- **Android release only / 本次仅发布 Android**
  Provided a universal APK (used by in-app updates) alongside separate APKs for `arm64-v8a`, `armeabi-v7a`, `x86_64`, and `x86` for manual installation. Desktop TUI packages ship on their own release cycle and are not included in this release.
  提供用于应用内更新的通用 APK，以及面向 `arm64-v8a`、`armeabi-v7a`、`x86_64` 与 `x86` 架构的独立安装包；桌面端 TUI 采用独立发布节奏，未包含在本次发布中。

- **Upgrading from v1.6.2 / 从 v1.6.2 升级**
  Preserved in-place update compatibility with v1.6.2 for official release builds. Because this major release rebuilds the core engine, you may need to reselect your workspace folder and reconfigure app settings after updating; existing Markdown workspace documents and attachments are not automatically deleted.
  保持原有包名与正式发布签名，支持从 v1.6.2 直接覆盖升级。由于本次大版本重写了核心引擎，升级后可能需要重新选择工作区目录并配置应用设置；现有的本地 Markdown 笔记与附件不会被自动删除。
