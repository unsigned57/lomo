## Lomo v2.0.2

Fixed workspace validation failures triggered by device timezone formats or unrelated Markdown files, upgraded the in-app diagnostics window into a share-ready error report, eliminated home card height jumps on return and checkbox toggle flicker, and refined Markdown code block and table rendering.

Lomo v2.0.2 修复了特定设备时区格式或目录内非笔记 Markdown 文件导致的打开失败问题，升级应用内诊断窗口为可直接复制上报的结构化错误报告，消除从二级页面返回主页时的卡片高度跳变以及勾选待办时的闪烁现象，并优化 Markdown 代码块与表格排版。

### ✨ New Features and Improvements / 新功能与改进

- **Share-ready diagnostics window / 更实用的诊断信息与一键复制报告**
  Upgraded Diagnostics under About Settings with device, app version, timezone, storage mode, and workspace readiness context, error-first filtering, sanitized error details with cause chains, and always-available one-tap report copying for easier troubleshooting.
  升级设置页“关于”中的诊断窗口，补充应用版本、设备、时区、存储模式与工作区就绪状态摘要，支持仅看错误/全部记录筛选、脱敏后的错误详情与调用链展示，以及随时可复制的完整诊断报告。

- **Styled code blocks and aligned Markdown tables / 代码块与 Markdown 表格排版升级**
  Added cleaner syntax container styling for fenced code blocks, balanced column sizing and header contrast for Markdown tables, and refined inline formatting inside note cards.
  优化笔记卡片内代码块容器与字体层次，改进 Markdown 表格列宽自适应与表头视觉对比度，并打磨行内样式渲染细节。

- **Safer read-only recovery and attachment routing / 增强只读恢复与附件目录随行策略**
  Retained the previously verified note view when a workspace falls back to read-only recovery and refined how image and voice attachments follow the note directory configuration.
  在工作区进入只读恢复状态时保留已验证的笔记列表可读性，并进一步梳理图片与语音附件跟随笔记目录存储时的路径策略与切换体验。

### 🐞 Bug Fixes / 缺陷修复

- **Workspace open failures on Android timezones and foreign files / 修复特定时区与非笔记文件导致目录打开失败**
  Accepted fixed-offset and abbreviated device timezone formats alongside standard timezone names when opening workspaces and statistics, and safely ignored non-daily or invalidly dated Markdown files (including extra files inside the trash subfolder) so existing third-party files in a folder no longer block workspace opening.
  兼容 Android 设备可能返回的固定偏移或缩写时区格式，并在打开目录时安全忽略非日记命名或日期无效的 Markdown 文件（含回收站子目录中的额外 Markdown 文件），避免其他工具遗留文件阻碍工作区打开。

- **Home return height jumps and todo-toggle flicker / 修复返回主页高度跳变与勾选待办闪烁**
  Eliminated visible card expand/collapse height jumps when navigating back to the home timeline, prevented card flickering or transient loading bars when checking off todos inside expanded notes, and removed redundant recompositions across the navigation host and drawer.
  消除从其他页面返回主页时笔记卡片高度重新测量导致的跳变与展开按钮闪烁，修复展开状态勾选待办时意外闪现进度条的问题，并减少导航与侧边栏带来的多余重组。
