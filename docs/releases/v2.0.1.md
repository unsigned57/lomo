## Lomo v2.0.1

Refined the Material 3 experience introduced in v2.0.0 with smoother filter and modal animations, natural search mode capsule transitions, unified haptic feedback, clearer workspace error explanations and diagnostics access, adaptive statistics cards, and complete note metadata in the Trash action menu.

Lomo v2.0.1 在 v2.0.0 的基础上进一步打磨 Material 3 交互细节与稳定性：统一筛选面板与各类弹窗的过渡动画，优化搜索模式悬浮切换条的阴影过渡，校准菜单与侧边栏的震动强度一致性，完善面向用户的错误说明与诊断入口，改进统计卡片布局，并在回收站操作菜单中恢复字数与创建时间统计。

### ✨ New Features and Improvements / 新功能与改进

- **Trash action menu metadata / 回收站菜单显示字数与创建时间**
  Restored the bottom metadata card inside the Trash note action menu to display creation time and character count consistently with the home timeline menu.
  在回收站笔记的底部操作菜单中重新加入信息卡片，展示创建时间与字数统计，与主页菜单保持一致。

- **Adaptive statistics card layout / 自适应统计卡片网格布局**
  Improved overview and time-distribution metric cards in Statistics to adapt column widths to card content without truncating numbers or labels with ellipses.
  优化统计页面的概览与时间分布卡片布局，使列宽自适应卡片文本内容，避免数字与标签因过窄而被省略号截断。

- **Diagnostics access and clearer error explanations / 诊断入口与更清晰的错误提示**
  Added direct access to recent diagnostics with one-tap report copying under About Settings, replaced raw technical error strings in recovery and settings prompts with clear failure explanations, and tightened folder-permission matching for storage access.
  在设置页“关于”分组中开放诊断查看与一键复制报告入口，将只读恢复页和存储提示中的原始技术信息替换为清晰易懂的错误说明与指引，并进一步收紧目录授权校验。

### 🐞 Bug Fixes / 缺陷修复

- **Filter panel and popup transitions / 修复筛选面板与弹出界面动画缺失**
  Added animated bottom status text transitions, color changes, and press-shape feedback across filter tiles, date fields, modal sheets, selection and theme dialogs, daily review options, quick-ball previews, reminder dialogs, and version history cards.
  为筛选面板的内容标签与日期项补齐底部文字升降和状态过渡动画，并将平滑的色彩变化、按压形变与展开动效普及到通用操作面板、选择弹窗、主题切换、每日回顾、快捷球预览、提醒弹窗与版本历史卡片。

- **Search mode capsule shadow transition / 修复搜索模式浮标显隐阴影过渡不自然**
  Aligned the exact/fuzzy search mode floating capsule with the home floating action button's synchronized scale, opacity, and elevation curve to prevent abrupt shadow artifacts while appearing or dismissing.
  参照主页悬浮球优化搜索页精准/模糊搜索切换浮标的显隐过渡，使缩放、透明度与阴影高度同步变化，消除出现与消失时的阴影突变与边缘发灰问题。

- **Consistent haptic feedback across menus and drawer / 统一菜单与侧边栏震动强度**
  Aligned haptic intensity across note action menus (including delete actions), navigation drawer entries and tags, filter date controls, gallery actions, and Trash menus, eliminating weak/inverted heavy triggers and duplicate haptics when opening sheets.
  统一主页菜单面板（含删除操作）、侧边栏导航与标签、筛选日期选择、图库操作及回收站菜单的点击震动强度，修正重震偏弱倒挂的问题并消除打开面板时的重复触发。
